# 롯데 서비스기획 AI 워크벤치

최종 수정본: 배포 버전 7 (2026-11-08), GitHub용 패키지 생성 2026-11-18.

## GitHub에 올리기
1. ZIP 압축을 풉니다.
2. GitHub 저장소에 압축을 푼 파일을 모두 업로드합니다. ZIP 자체를 업로드하지 마세요.
3. 저장소 최상위에 index.html이 있어야 합니다. 상위 폴더로 감싸지 마세요.
4. Settings → Pages에서 Deploy from a branch를 선택하고 main 브랜치의 /(root)를 지정해 저장합니다.
5. 배포 완료 후 표시되는 사이트 주소로 접속합니다.

별도의 설치·빌드·API 키가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다.
.openai 폴더는 GitHub Pages에 필요하지 않아 포함하지 않았습니다.
.nojekyll은 정적 파일을 그대로 서비스하기 위한 파일입니다.

## 반영된 내용
- 교육실습과 현업활용 모드 구분 및 별도 저장
- 7개 계열사별 교육실습 예시와 작성 내용 보관
- 현업활용 계열사 변경 시 담당 서비스·대상 고객·기획 목적 빈칸 처리
- 첫 실습의 프롬프트 5요소, 이후 실습의 공통 지시 중복 제거
- 홈의 예시로 체험하기 버튼 및 기능 삭제
- [교육용 가상 예시] 표시 삭제, 오타 및 표현 정리

## 저장 및 이전
입력 내용은 접속한 주소의 브라우저에 저장됩니다.
기존 ChatGPT 사이트의 입력 내용은 GitHub 사이트로 자동 이전되지 않습니다.
기존 사이트에서 프로젝트 저장 → 새 사이트에서 불러오기를 사용하세요.
교육실습과 현업활용은 각각 해당 모드에서 저장할 수 있습니다.
AI 답변은 직접 붙여넣는 방식이며 API 연동 비용이 발생하지 않습니다.
